The Neo-Brutalist structure of crisp tactile physics, fused with the organic warmth of Swiss design.

DMaven Design System (Warm Fusion) was born from the desire to break free from sterile, flat gray minimalism. It unites bold 2.5px tactile borders and hard offset drop shadows with organic cream canvases, Phosphor Icons, and rich multi-color harmony.

The Design Genesis

Why We Built Warm Fusion

Most brutalist systems feel punishingly cold, and most corporate systems feel boringly flat. Warm Fusion is the intentional middle ground.

Pillar I

The Neo-Brutalist Bone

Rigid 2.5px borders, hard 5px drop shadows with zero blur, and physical press animations. It anchors the interface with tactile weight and confidence.

Pillar II

The Swiss Typographic Soul

Warm organic cream grounds (#F9F6F0), generous whitespace, human-centered type (Bricolage Grotesque & Instrument Sans), and 16px/22px rounded corners.

Pillar III

Multi-Color Brand Harmony

Purposefully balanced for rich brand color palettes (Deep Navy, Sacred Terra, Emerald Growth, Warm Gold, Brilliant Blue) without visual noise.

        Architecture
        
Tailwind CSS vs Radix UI: Use Either or Both

        
DMaven Design System is architected in two clean tiers so you never have to fight unwanted dependencies.

      


      

        

          Tier 1 · Pure Tailwind CSS
          
Zero-JS Styling Layer

          

            Use DMaven Warm Fusion utility classes in pure HTML, Vue, Svelte, or Astro. No React runtime or external component baggage required.
          

          
<button class="bg-terra text-white font-display font-bold px-6 py-3 rounded-wf-pill border-wf border-forest shadow-wf active:translate-x-0.5 active:translate-y-0.5">
  <i class="ph-bold ph-lightning"></i> Primary Button
</button>

        


        

          Tier 2 · React + Radix UI
          
Accessible Headless Engine

          

            Drop-in React components with unstyled Radix primitives for keyboard focus trapping, ARIA dialogs, and sheets wrapped in DMaven tokens.
          

          
import { Button, Dialog, Drawer, Toast } from "@dmaven/design-system";
import { Lightning } from "@phosphor-icons/react";

export default function App() {
  return <Button variant="primary"><Lightning weight="bold" /> Interactive Action</Button>;
}
